      Local multiplayer
      Up to 4 gamepads

      Press a button to connect a gamepad, then select a multiplayer mode in the game. Click the game screen to use the keyboard. In-game memory-card saves are kept in this browser when storage is available.

      Xbox / XInput, DualShock 4 and DualSense connect automatically. Press any controller button to activate it. A / Cross accelerates and confirms, X / Square brakes, B / Circle uses items and goes back, LB / RB or L1 / R1 drifts, and Menu / Options pauses.

      All playable characters are unlocked. Online races use your own camera; shared-screen lobbies use the host's screen.
